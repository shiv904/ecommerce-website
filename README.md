# ShopSmart — E‑commerce Frontend

A modern, responsive e‑commerce storefront built with plain HTML, CSS, and JavaScript.

## Features

- Responsive layout with navbar, hero, and product grid
- Search, category filter, and sorting (price/rating)
- Product quick view modal with quantity selector
- Cart drawer with add/update/remove, subtotal, and persistence via localStorage

## Getting Started

1. Open `index.html` in your browser.
2. Everything is client‑side and works offline (product images load from the web).

## Notes

- Product data is seeded in `assets/js/app.js` for simplicity.
- Images are served from `https://picsum.photos` using stable seeds.
